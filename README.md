# SkillBridge 🤝

### Bridging communication through AI-powered sign recognition

SkillBridge is an interactive, AI-powered communication platform designed to make gesture-based communication more accessible. It combines sign recognition with a text-building interface and speech synthesis, helping users convert recognized gestures into meaningful text and spoken output.

## ✨ Key Features

- **Gesture Recognition:** Interpret supported signs through the recognition interface.
- **Sentence Builder:** Combine recognized signs into a continuous text output.
- **Text-to-Speech:** Convert generated text into spoken audio.
- **Text Editing Controls:** Undo the latest addition, clear the sentence, and copy the generated text.
- **Interactive Interface:** A clean, responsive experience designed for accessible communication workflows.

## 🛠️ Technology Stack

- React and TypeScript
- Vite
- Machine-learning-based gesture recognition
- Web Speech API for speech synthesis

## 🎯 Project Goal

To explore how AI-driven gesture recognition and speech technologies can support more accessible communication experiences.

## 🚀 Future Improvements

- Expand the supported sign vocabulary
- Improve recognition accuracy across different lighting and backgrounds
- Add multilingual speech output
